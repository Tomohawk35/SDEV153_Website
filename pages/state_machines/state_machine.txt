What is a state machine?

A state machine, or finite state machine, is a programming pattern that breaks down the complex behavior of an object into smaller, more manageable actions and their respective events/responses.

A common method, especially in Godot, is to use a Node-based State Machine. 
This involves setting up a base node to act as your overarching controller for states and then adding child nodes to that controller for each individual state.
