Implementing a Day/Night Cycle System

In this tutorial, we will go over how to implement a day/night cycle system in Godot. Many games feature this mechanic to create a more immersive experience. It can also be used to affect gameplay elements such as enemy behavior, lighting conditions, or plant growth.

A day/night cycle system can be implemented in various ways, but one common approach is to use a global autoload (singleton) to manage the time of day and update the environment accordingly. This allows for easy access to the time of day from any scene in the game. These are generally pretty simple as they are only focused on keeping track of time.

The script below demonstrates a simple manager class that keeps track of the time of day and day number. It also provides a signal that can be connected to other nodes in the game to update their behavior based on the time of day. For example, a plant object could connect to the new_day signal to update its growth stage.
