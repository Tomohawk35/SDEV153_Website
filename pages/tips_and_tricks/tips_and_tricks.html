Hotkeys

Hotkey Conditions Function
Ctrl + A A node is selected in the Scene Tree Opens a window to search and add a basic node as a child of the selected node

Alt + UP or Alt + DOWN Script Editor - Cursor is placed in a line or multiple lines are highlighted (full lines do not need to be highlighted) Shifts the selected lines up or down in the script. Helpful for quickly moving chunks of code.

Process vs Physics Process

Let's quickly chat about the _process(delta: float) and _physics_process(delta: float) functions. Godot Nodes have many built functions ready to use out of the box. The _physics_process(delta: float) function is a function that is called at a fixed rate (60 times per second by default) which results in a consistent time delta. This makes it good for performing physics-related calculations or operations, such as movement or collisions. The _process(delta: float) function is called once for each rendered frame, which can vary depending on how well the system is running. This makes it the ideal spot for performing graphics-related operations, such as animations and particle effects.

Many beginner Godot users will jump into tutorials and start throwing all of their code into these two built-in functions. This can quickly begin to bog down the system if you are doing large amounts of calculations or updates every frame even when unnecessary. A way to solve this issue is an event-based system, or Godot's signals.

Godot uses signals to broadcast when a specific event occurs. These signals can be connected to by other objects that may want to perform a certain action when an specific event occurs. Let's use a simple example: a health bar.

A player may have a health value and a health bar for displaying that value to the player. A player's health is typically not changing constantly, so it is unnecessary to update the health bar every process frame. It only needs to update when the health of the player actually changes. So let's use a signal to announce when the player's health changes.
